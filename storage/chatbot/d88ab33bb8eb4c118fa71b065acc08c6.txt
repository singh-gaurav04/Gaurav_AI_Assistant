OTHER PROJECT
ShareMySecret (web), 2026. ShareMySecret lets people share passwords, API keys, and other sensitive information through encrypted, auto-expiring links instead of leaving them in chat or email. I co-founded it and lead it as CTO. Messages are encrypted in memory with AES-GCM using a random salt and nonce, and are never written to disk. Zero storage: there is no database; the encrypted payload is encoded into a URL-safe token that becomes the shareable link. Links self-destruct after a sender-chosen expiry time; the server checks expiry before decrypting. Secrets can be shared by copying the link or scanning a QR code. Tech stack: React, React Router, Tailwind CSS, Framer Motion, AES-GCM, Netlify. Live site: https://sharemysecret.netlify.app/ Source code: https://github.com/singh-gaurav04/Secret_share
